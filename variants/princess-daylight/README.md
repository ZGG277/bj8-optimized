# 公主请开球

本目录是公主游戏的唯一维护源码，独立于仓库根的中八台球。内部包版本1.1.0，本分支保存2026-10-25已完成本地体验版；不将GitHub同步等同小红书发布。

保留10位随机陪练、友好AI、暖灰有拼缝地板、哑光象牙金线桌体、宝石球、双指视角与原声开场。10/25调整包括1.15倍速完整开场（13.097秒）、石板细纹、更厚碰撞声、低音量鸟鸣流水以及宿主顶部按钮避让。普通网页构建修复外置媒体/字体的相对资源路径。

已有关注作者入口位于暂停菜单，只有宿主版本和能力支持时显示，点击才调用官方确认。此代码保全在本分支，但原生关注验收、Android/iOS以及新版平台发布仍未完成。1.0.4已发布包/原15秒素材保留在本地恢复记录，不能用本分支替代其来源证明。

## 运行与构建

Node24、npm11。在本目录运行 `npm ls --depth=0`；首次缺依赖时 `npm ci --ignore-scripts`。`npm run typecheck`、`npm run build`、`npm test` 分别做类型、普通构建、单元验证；`npm run dev -- --host 127.0.0.1` 后以 `?world=castle` 进入城堡。小工具构建命令为 `npm run build:minitool`，平台规范需在上传前重新核对。

运行模型、字体和图像在src内；`scripts/build-daylight-lod.py` 仅在重新派生模型时使用同仓相邻daylight-1009历史模型，常规构建无需重做Blender。源码来源/公开化差异及逐文件SHA见PUBLIC_SOURCE_MANIFEST.json，素材来源见仓库根ASSET_SOURCES.md和本目录ASSET_PROVENANCE.json。

公开副本只清理了非运行元数据中的个人路径/提示词、离线作者脚本的本机输出路径和过时说明；游戏运行代码与核准10/25版本一致。
