# opponent/

随机十位陪练的友好风格只改变选杆和一次性执行误差，物理、八球规则与玩家输入不变。

- model.ts：保留原有玩家能力评估和v1/v2/v3迁移；仅在整局结束时更新画像
- friendly-style.ts：局前按准度/走位锁定，陪练/挑战上限48/62；基础机会尝试率62%/46%，连败、领先或连续进球时进一步让球，不选择防守，不强制胜负
- companions.ts：同龄同肤色、统一插画风格的十个姓名和头像；每局固定身份，重开不立即重复，胜局由本局陪练祝贺
- position-observation.ts：普通进球后按下一杆几何机会评估走位，不要求先启用规划辅助；最近六局胜负单独记录，用于下局难度缓和
- tactical-shot.ts：机会杆最多9次仿真（含两个小幅边界扰动探针）且计入总预算；只接受理想结果合法、不落袋、留给玩家有限难度几何线路的普通击球。普通进攻验证合法首碰、目标入袋、不洗袋且不提前带进8号；不同球/袋的替代路线提供变化。理想选杆验证不能保证执行后结果
- execution.ts：生产和校准共用一次性误差采样；友好中心接触杆使用保守角度/力度波动，普通进攻保留较宽误差，不按结果重抽
- tactical-worker.ts / tactical-async.ts：有硬仿真预算、截止与取消的Worker；小工具消费相同步进生成器
- friendly-style.test.ts：固定档位、有限误差、合法理想机会、不强制玩家获胜
- scripts/friendly-calibration.test.ts：固定种子合成局面与有截断标记的短局，不代表真人胜率或乐趣

无验证球路时仍可能出现普通瞄准/解球失败；犯规由原规则处理，不掩盖或免罚。

小工具的合作式搜索只在完整仿真之间让出执行；8ms切片和截止不是单次仿真的硬抢占，云端计时不能代表手机温升。

- companion-collection.ts：独立v1收藏存档；只按已完成胜局解锁本局身份，重复胜利累计次数，不从旧总胜局推断身份；旧存档不清理。
- companion-card-art.ts：同一陪练专属表情资产及赞美文案，比赛头像保持原图。
