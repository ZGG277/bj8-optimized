# opponent/

随机十位陪练的友好风格只改变选杆和一次性执行误差，物理、八球规则与玩家输入不变。

- model.ts：保留 v1/v2/v3 迁移。已完成对局累计准度和走位样本，保留最近六局明细。
- friendly-style.ts：综合历史准度、走位与已校准实力锁定下一局；胜负不参与。满级前陪练档位略高于公主；连让三杆后的下一杆正常进攻。
- companions.ts：同龄同肤色、统一插画风格的十个姓名和头像；每局固定身份，重开不立即重复，胜局由本局陪练祝贺
- position-observation.ts：按真实结算记录出杆。准度包含明确的近距离角度失手，路线看合法进球后是否留下可打的下一杆，规划辅助样本折权；近六局胜负单独记录
- tactical-shot.ts：优先打明显可进的球。难球可试轻微偏离进球线；友好机会杆需真实合法换手且为公主留可打路线。最多九次仿真并计入总预算。
- execution.ts：生产和校准共用一次误差采样；明显进球与友好机会杆缩小误差。真实出杆后不重抽。
- tactical-worker.ts / tactical-async.ts：有硬仿真预算、截止与取消的Worker；小工具消费相同步进生成器
- friendly-style.test.ts：覆盖实力档位上限、明显球优先、有限误差、合法理想机会以及黑八正常结束。
- scripts/friendly-calibration.test.ts：固定种子合成局面与有截断标记的短局，不代表真人胜率或乐趣

无验证球路时仍可能出现普通瞄准/解球失败；犯规由原规则处理，不掩盖或免罚。

小工具的合作式搜索只在完整仿真之间让出执行；8ms切片和截止不是单次仿真的硬抢占，云端计时不能代表手机温升。

- companion-collection.ts：独立v1收藏存档；只按已完成胜局解锁本局身份，重复胜利累计次数，不从旧总胜局推断身份；defeatedCompanionNames按首次获胜排序/去重，包含当前已赢但尚未落盘的身份，供分享正文使用；不在分享时写记录，旧存档不清理。
- companion-card-art.ts：同一陪练专属表情资产及赞美文案，比赛头像保持原图。

2026-11-05：companion-moments.ts 保留十位陪练的独立思考口吻；进球等语境改由下述事实适配器选词，不参与AI，不修改收藏卡原句。

- companion-dialogue-bank.ts：用户原话术库中已映射的30场景/90句，保留原句、优先级、概率与语义限额；原件/来源指纹在本轮artifact，不接入未知物理埋点。
- companion-dialogue.ts：消费原规则最终结算，在本局按出杆去重、区分同杆多球与连续得分杆、处理具体犯规及本组清空后的8号阶段；最高事实场景只抽一次概率。12秒/至少隔2杆、每局最多7句、同类限额、局内不重复与最近3局降权；仅组件实际展示回执消费预算。思考最多一次且共享限频，不延迟AI；终局由既有赞美卡/安慰句负责。历史只在本次页面会话内保存。
- companion-dialogue.test.ts：结合真实八球结算验证犯规优先、提前黑八静默、有效球去重、连续得分杆、冷却/预算、取消及重开，不借参考选择器的自测冒充游戏接入验收。
