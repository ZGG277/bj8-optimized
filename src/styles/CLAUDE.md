样式体系：按 base → layout → controls 顺序加载，后者可覆盖前者；横屏尺寸令牌统一在 base 重定义。v1.3 统一采用“静谧球房”深绿黑烟熏表面，并借用“竞技仪表”的状态层级与等宽数字秩序。

## 成员清单

`base.css`: 设计令牌（色彩/两级表面/三级文字/圆角/阴影/动效/--scoreboard-h/--control-deck-h/--hud-safe-top）、全局重置、焦点环、减弱动态偏好与动画；桌面只保留 48px 比分栏，横屏只保留 34px 状态栏。

`layout.css`: 无产品/回合/杆数顶栏的桌面壳层、烟熏比分板、球桌舞台、遮罩与带能力摘要/陪练挑战入口的品牌开始界面；桌面/手机默认给 54px 右侧控制轨预留球桌安全区，竖屏把球组/进球状态压入 34px 单行；含胜利庆祝动画。

`controls.css`: 桌面/手机共用 54px 烟熏单手轨与统一状态阶梯；长按整轨进入编辑时四控件共同轻微抖动；视角推杆与出杆区等长，另含 48px 灯泡、仪表化击球点、统一浮层，以及球桌内固定中心线/移动刻度的横向无限瞄准拨轮。
