# styles/

> L2 | 父级: `../CLAUDE.md`

样式体系：按 base → layout → controls 顺序加载，后者可覆盖前者；横屏尺寸令牌统一在 base 重定义。

## 成员清单

`base.css`: 设计令牌（色彩/字体/--scoreboard-h/--control-deck-h/--hud-safe-top)、全局重置、焦点环与动画；删除产品顶栏高度，桌面只保留 48px 比分栏，横屏只保留 34px 状态栏。

`layout.css`: 无产品/回合/杆数顶栏的桌面壳层、紧凑比分板、球桌舞台、遮罩与开始界面；桌面/手机默认给 54px 右侧控制轨预留球桌安全区，竖屏把球组/进球状态压入 34px 单行；含胜利庆祝动画。

`controls.css`: 桌面/手机共用 54px 右侧黑色单手轨；长按整轨进入编辑时四控件共同轻微抖动；视角推杆与出杆区等长，另含 48px 灯泡、击球点，以及球桌内固定中心线/移动刻度的横向无限瞄准拨轮。
