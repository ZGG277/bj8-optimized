# components/

> L2 | 父级: `../CLAUDE.md`

HUD 控制组件层：只渲染控件并把事件转发给 Game/input 层，不持有对局或物理状态。

## 成员清单

`ViewToolbar.tsx`: 无文字连续视角推杆；俯视端点与手动相机开关共享紧凑图形分段，右侧停靠时下端第一人称/上端俯视，底部停靠时左低右高，顾燃观战时整体禁用，玩家回合稳定长按不先改变数值，快速拖动与键盘仍连续提交 0..1。

`Scoreboard.tsx`: 桌面与手机都在“你/顾燃”名字下展示整数水平并在跳变时短促过渡；同时渲染实际球组/进球状态。

`TableStage.tsx`: 精简球桌区域；默认左右微调与按需 AimDial 均并入统一五控件层。显式暴露瞄准/手动相机模式供触控门禁与光标反馈；顾燃等待及击球阶段显示固定俯视提示，观战球桌不接收环绕输入，提示本身不拦截触控；玩家回合保留独立手动环绕，结束覆层仍独占交互。

`FirstMatchGuide.tsx`: 首局非模态一行微提示；按步骤寻找球桌、瞄准微调槽、视角、击球点或蓄力控件真实 DOM 锚点，以标签自身实测宽高随控件出现/移动/视口变化立即避让定位；精瞄阶段默认提示使用球杆左右键，提示本体穿透交互，只保留 44px 弱化 ×，具备跳过新手引导的 aria 名称与 live 语义，不提供手动“下一步”。

`FirstMatchGuide.test.tsx`: 服务端静态结构回归，锁定短文案、具名跳过入口，并拒绝“下一步/完成”按钮回潮。

`ControlDeck.tsx`: 五控件统一编排层；组合 ViewToolbar、灯泡三开关、SpinControl、ShootControl 与共享同一槽位的默认 AimControls / 按需 AimDial，按 desktop/portrait/landscape 恢复布局。拨轮只在灯泡第三入口显式开启后替换左右键；其余布局长按、吸附、换位与内容手势门禁保持不变。

`ControlDeck.test.ts`: 控件内容意图与布局意图互斥回归，覆盖慢速瞄准/蓄力跨过长按时限仍不移动控件，以及静止长按仍能进入布局。

`PlanOverlay.tsx`: 半透明紧凑走位浮层；只取最高概率方案，默认第 1 杆，用户点击第 2/3 杆标签后才切换对应单杆路线；带独立拖拽手柄，场景渲染委托 Scene3D。

`ReviewOverlay.tsx`: 半透明可拖动击球复盘浮层；折叠态一句话诊断，展开态展示 verdict、诊断与计划/实际图例，场景对比委托 Scene3D。

`IntroScreen.tsx`: 开始界面，展示持久化玩家水平/置信度，并提供陪练与挑战两种局前对手关系入口。

`AimDial.tsx`: 无文字无限拨轮；右侧停靠改用上下拨动，底部/自由位置左右拨动，轻点或 Enter/Space 显式切换粗/精档，方向键拨动，以中心圆环、刻度密度、主题强调色及压感紧度环表达当前手感，不展示或推断目标袋口。

`AimDial.test.tsx`: 默认粗档、显式精瞄状态、无自动“接近”语义与无障碍数值的静态结构回归。

`AimControls.tsx`: 默认球杆左右微调；左右 56×48 大触控键夹住球杆中线，单击提交固定 0.004rad 精瞄步长，按住 320ms 后以 140ms 间隔低速连续提交；按钮长按优先于控件布局拖位。

`AimControls.test.tsx`: 左右按钮、球杆中线、禁用语义及精瞄步长/低速长按节奏回归。

`SpinControl.tsx`: 纯母球+撞击点视觉；点击/拖动经 clampSpin 映射单位圆，稳定长按不会先改杆法，竖屏小预览仍可展开大盘。

`ShootControl.tsx`: 纯球杆回缩/前冲与压缩能量带视觉；右侧向下、底部向右蓄力，沿蓄力正方向可拉到屏幕边缘，横向或反方向移出带 24px 容错的有效走廊后松手会取消且不出杆；85% 后转暖色，不显示标题、提示或数字，保留 meter/键盘语义。

`ShootControl.test.ts`: 横竖蓄力提交走廊回归，锁定正方向满行程、侧向/反向逃逸取消及 24px 边界容错。

`ThemeSwitcher.tsx`: 常驻左下角的小调色盘入口；点按后才展开“青瓷 / 决赛之夜 / 霓虹球房”，选择后自动收起，仍校验 URL 参数、持久化本地选择并提供 `[` / `]` 键盘轮换。
