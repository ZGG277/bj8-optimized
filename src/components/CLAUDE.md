# components/

> L2 | 父级: `../CLAUDE.md`

HUD 控制组件层：只渲染控件并把事件转发给 Game/input 层，不持有对局或物理状态。

按钮与可操作控件通过稳定 `data-control-tip` 接入逐控件提示；本层只在真实状态改变、非取消手势提交或菜单动作成功时报告学习，出杆由 Game 确认物理成功。提示纯展示、无触控拦截，学习状态独立于首局步骤引导。

## 成员清单

`ControlOnboarding.tsx`: 全局唯一的非模态控件说明；真实鼠标悬停/键盘焦点/触屏按下均按当前锚点左侧定位，左贴屏时上方避让，穿透全部交互；触摸立即出现且松手后短暂停留，不受已学会状态限制，鼠标/键盘的一般提示仍在学会后隐藏，俯视/手动视角/出杆保留常驻速查；动态 `data-control-tip-copy` 同帧更新并以 aria-describedby 关联，只在显示时观察布局变化。

`ControlOnboarding.test.tsx`: 提示左侧优先/左贴屏避让纯几何，以及视角、瞄准、杆法、出杆稳定 ID 的服务端结构回归。

`ControlLearningActions.test.tsx`: SSR 捕获真实拨轮/方向键处理器，验证布尔成功回执、边界无变化、成功松手、取消/禁用和长按累积，不把原始输入行程当成学习成功。

`ViewToolbar.tsx`: 无文字连续视角推杆；俯视端点与手动相机开关共享紧凑图形分段，右侧停靠时下端第一人称/上端俯视，底部停靠时左低右高，顾燃观战时整体禁用；俯视与手动相机按真实开关状态提供常驻速查，四项操作各自学习，端点无变化/取消不学习，稳定长按不先改变数值，快速拖动与键盘连续提交 0..1。

`Scoreboard.tsx`: 桌面与手机都在“你/顾燃”名字下展示整数水平并在跳变时短促过渡；同时渲染实际球组/进球状态。

`TableStage.tsx`: 精简球桌区域；显式暴露瞄准/手动相机模式；顾燃观战锁定俯视，玩家保留独立环绕；结束覆层独占交互，并展示本局唯一训练重点与下一局目标。

`FirstMatchGuide.tsx`: 首局非模态一行微提示；按步骤寻找球桌、瞄准微调槽、视角、击球点或蓄力控件真实 DOM 锚点，以标签自身实测宽高随控件出现/移动/视口变化立即避让定位；精瞄阶段默认提示拨动瞄准轮，提示本体穿透交互，只保留 44px 弱化 ×，具备跳过新手引导的 aria 名称与 live 语义，不提供手动“下一步”。

`FirstMatchGuide.test.tsx`: 服务端静态结构回归，锁定短文案、具名跳过入口，并拒绝“下一步/完成”按钮回潮。

`ControlDeck.tsx`: 五控件统一编排层；组合 ViewToolbar、灯泡四开关、SpinControl、ShootControl 与默认 AimDial / 可选 AimControls，按 desktop/portrait/landscape 恢复布局。首段内容移动也通过既有事件重派发交回控件，不再旁路调用拨轮，确保真实变化回执属于完整手势；触屏 Pointer/contextmenu 取消浏览器默认长按行为；复盘与走位独立，布局长按/吸附/换位门禁不变。

`ControlDeck.test.ts`: 控件内容意图与布局意图互斥回归，覆盖慢速瞄准/蓄力跨过长按时限仍不移动控件，以及静止长按仍能进入布局。

`PlanOverlay.tsx`: 半透明紧凑走位浮层；只取最高概率方案，默认第 1 杆，用户点击第 2/3 杆标签后才切换对应单杆路线；带独立拖拽手柄，场景渲染委托 Scene3D。

`PlanStatusNotice.tsx`: 走位开关的即时状态反馈；计算中显示脉冲提示，无可靠直攻路线时明确说明并允许关闭，避免只有灯泡亮灭变化。

`PlanStatusNotice.test.tsx`: 服务端静态结构回归，锁定 computing/failed 两种提示和具名关闭入口。

`ReviewOverlay.tsx`: 半透明可拖动击球复盘浮层；统一以“复盘”开头的中性诊断，不使用顾燃口吻且自主杆不提供答案轨迹，只有显式计划复盘才出现 ▶ 并展开计划/实际图例，场景对比委托 Scene3D。

`IntroScreen.tsx`: 开始界面，展示持久化玩家水平/置信度，并提供陪练与挑战两种局前对手关系入口；正式入口只提供室内、云海与湖面，局内无切换。

`AimDial.tsx`: 无文字无限拨轮；右侧上下拨动、底部/自由位置左右拨动，轻点或 Enter/Space 显式切粗/精档；逐控件学习只消费 onAdjust/onTogglePrecision 布尔回执，Pointer 累积真实变化至非取消松手，边界钳制无变化不学习。

`AimDial.test.tsx`: 默认粗档、显式精瞄状态、无自动“接近”语义与无障碍数值的静态结构回归。

`AimControls.tsx`: 灯泡可选的球杆左右微调；左右 56×48 大触控键夹住球杆中线，单击提交固定 0.004rad，按住 320ms 后以 140ms 连续提交；逐控件学习按 onAdjust 布尔回执累积，只在非取消松手或成功键盘激活后提交，按钮长按优先于布局拖位。

`AimControls.test.tsx`: 左右按钮、球杆中线、禁用语义及精瞄步长/低速长按节奏回归。

`SpinControl.tsx`: 纯母球+撞击点视觉；点击/拖动经 clampSpin 映射单位圆，稳定长按不会先改杆法，竖屏小预览仍可展开大盘。

`ShootControl.tsx`: 纯球杆回缩/前冲与压缩能量带视觉；右侧向下、底部向右蓄力，沿蓄力正方向可拉到屏幕边缘，横向或反方向移出带 24px 容错的有效走廊后松手会取消且不出杆；85% 后转暖色，按停靠方向提供常驻速查且禁用时保持只读，保留 meter/键盘语义与悬停提示锚点，学习只由 Game 物理成功路径确认。

`ShootControl.test.ts`: 横竖蓄力提交走廊回归，锁定正方向满行程、侧向/反向逃逸取消及 24px 边界容错。

`ThemeSwitcher.tsx`: 保留三主题解析、首帧应用、持久化与可恢复的调色盘组件；当前应用入口不挂载选择器，因此不向玩家展示调色盘，URL 与本地偏好仍生效。
