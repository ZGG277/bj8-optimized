## 成员清单

`model.ts`: 自适应对手纯领域模型——所有真实玩家出杆只在整局结束时一次结算，技术分严格由准度 72% 与走位 28% 组成；同批事实只选择犯规/准度/走位/稳定中的一个训练重点和下一局目标；把画像映射为陪练 +3 / 挑战 +10 及独立战术预算；含 v1/v2→v3 安全迁移。

`tactical-shot.ts` / `tactical-worker.ts` / `tactical-async.ts`: 顾燃专用限预算选杆链。先均匀验证前 N 条路线的中/低/高杆，再在剩余预算内小角度标定；只返回真实进目标球、首碰合法且母球不洗袋的杆，战术分数叠加终局的下一杆可打性；无直接线路时，实力 50 及以下仍选择目标球→袋口的进攻意图，51 起才允许主动安全球；Worker 超时直接终止，禁止主线程重算。

`model.test.ts` / `tactical-shot.test.ts` / `tactical-async.test.ts`: 覆盖整局一次提交、单点训练总结优先级、辅助降权、0–100 边界、+3/+10、近袋安全中杆的真实进球/避洗袋、Worker 抢占/超时与 v1/v2 迁移。
